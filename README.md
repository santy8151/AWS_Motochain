# AWS MotoChain Professional

Proyecto demostrativo para portafolio Cloud Engineer.

## Arquitectura
- Onion Architecture
- FastAPI
- Solidity Smart Contracts
- Docker
- Preparado para AWS ECS, EC2, S3, IAM y CloudWatch

## Módulos
Auth, usuarios, perfiles, menú, compras, stock y ventas.

## Blockchain
Contratos Solidity optimizados para reducir gas usando eventos y almacenamiento mínimo.

## Despliegue
La carpeta aws contiene plantillas base para infraestructura.
